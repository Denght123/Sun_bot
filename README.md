# 基金理财热点消息机器人

一个面向个人微信场景的财经热点日报机器人。

项目目标是：每天自动抓取多平台财经相关热点，经过规则筛选与大模型摘要后，在每天早上 **08:00** 生成一份统一的财经早报，并通过个人微信发送给用户。

## 项目定位

这个项目聚焦于“**统一收集 + 精简总结 + 定时推送**”三件事：

- 打破信息分散，集中汇总财经热点
- 用大模型做后台分析与摘要，提升阅读效率
- 以固定节奏输出统一内容，不做个性化推荐

当前版本为 **MVP / 单用户测试版**，重点验证内容质量、稳定性和自动推送链路。

## 当前能力范围

### 已定义的核心能力
- 多源抓取财经相关热点
- 对热点进行去重、聚类、筛选与摘要
- 生成固定结构的完整精简版日报
- 每日 08:00 自动推送
- 支持微信关键词交互查询
- 失败自动重试与异常告警

### 当前支持的数据方向
- 社交热点：抖音、微博、知乎、B站、百度
- 财经媒体：财联社、凤凰网财经、今日头条财经

说明：并不是所有热搜都会进入日报，系统只保留与 **财经、政策、行业、资本市场直接相关** 的内容，泛娱乐热点不会进入正文。

## 日报内容结构

每日早报默认输出完整精简版，包含以下模块：

1. 今日总览（3-5条）
2. 热门财经板块（Top10，行业赛道口径）
3. 国内政策与监管动态（Top10）
4. 国际事件与海外市场影响（Top10）
5. 风险提示（2-3条）
6. 原文链接集合
7. 固定免责声明

### 内容风格
- 先事实，后影响
- 中性克制，不提供投资建议
- 同一时刻所有用户接收统一文本

## 交互方式

用户可通过微信关键词查看不同模块内容：

- `功能`
- `早报`
- `板块`
- `政策`
- `国际`
- `热搜`
- `风险`
- `帮助`

这意味着系统不仅支持每日固定推送，也支持用户在微信中按模块补充查看详情。

## 技术方案概览

项目采用“**云端负责生成，Windows 发信端负责发送**”的分离式架构：

### 云端（阿里云 ECS）
负责：
- 数据抓取
- 内容清洗与规则处理
- 大模型摘要生成
- 日报生成
- 定时调度
- 发送任务下发
- 状态监控与告警

### 本地 / 专用 Windows 发信端
负责：
- 维持个人微信登录态
- 接收云端发送任务
- 执行真实微信发送
- 回传发送结果
- 定期上报心跳与状态

### 核心技术栈
- Python + FastAPI
- APScheduler（MVP 默认调度）
- Playwright + Requests / BeautifulSoup
- PostgreSQL + Redis
- Docker
- 大模型 API

## 系统工作流程

系统每天按以下节奏运行：

1. 前一日 18:00 至当日 07:30 收集数据
2. 07:30 - 07:45 进行去重、聚类、规则筛选
3. 07:45 - 07:55 调用大模型生成摘要
4. 08:00 下发发送任务并完成微信推送

如果发送失败：
- 自动重试最多 3 次
- 仍失败则触发异常告警

## 为什么这样设计

这个方案不是把所有逻辑都堆在一台本地电脑上，而是把职责拆开：

- **阿里云 ECS** 负责稳定运行与定时调度
- **Windows 发信端** 负责个人微信自动化发送

这样做的好处是：
- 不依赖个人电脑长期开机来完成抓取和摘要
- 保留个人微信测试版的低成本验证方式
- 后续如果迁移到企微、公众号或多人广播，云端架构可以继续复用
